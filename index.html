              (08)

              Data

              Progres tersimpan di browser ini, dan di akunmu kalau kamu masuk.

              Kunci localStorage aidev-tracker-v1. Ekspor ke progress.json untuk cadangan, atau taruh file itu di repo GitHub Pages supaya orang lain bisa melihat progresmu dalam mode lihat.

              Hapus semua progres di browser ini? Tugas, proyek, kebiasaan, dan log akan hilang dan tidak bisa dikembalikan. Ekspor dulu kalau ragu. Sinkron aktif: data di akunmu dan semua perangkat juga ikut terhapus. Untuk mereset perangkat ini saja, keluar dari akun dulu.

              Pakai seperti aplikasi — tetap jalan tanpa internet

              Di iPhone atau iPad: buka di Safari, ketuk Bagikan, lalu Tambah ke Layar Utama.

              Belum masuk

              Satu akun, semua perangkat.

              Masuk dengan akun yang sama di HP, laptop, dan tablet. Progres ikut ke mana pun kamu masuk: centang di HP, langsung muncul di laptop. Tetap jalan tanpa internet; perubahan dikirim saat online.

              atau dengan email

              Login akun belum diaktifkan di situs ini. Pemilik situs perlu mengisi js/firebase-config.js (lihat README, bagian Akun). Sampai saat itu progres hanya tersimpan di browser ini.

              Sinkron lewat GitHub Gist sudah dihapus dan tokennya dilupakan di perangkat ini. Progresmu tetap ada di sini; masuk ke akun supaya tersinkron lagi. Gist lamanya bisa kamu hapus sendiri di gist.github.com.

              Setiap perubahan dikirim otomatis. Perubahan dari perangkat lain langsung dimuat.

              Bagikan progres

              Link baca-saja yang selalu memakai data terbaru: checklist, kebiasaan, log, dan proyek. Refleksi mingguan tidak ikut.

              Hapus akun dan semua datanya di cloud? Progres di akun dan link bagikan dihapus permanen dan tidak bisa dikembalikan. Data di browser ini tetap ada; ekspor dulu kalau perlu. Keluar dulu dari akun di perangkat lain.
